# 插画生成简报

本次插画使用内置图像生成工具，未使用外部素材商店或图像生成 API。用户提供的 T1、T2、T3、T4_blonde、T5_blonde 为人物身份、画风和服装参考。最终使用的 PNG 位于 `public/wardrobe/assets/`；全局坐标与五套配色在 manifest。

共同要求：成年男青年、清晰日式二次元线稿与赛璐璐明暗、略朝右侧的四分之三站姿、双手放下、不插兜、统一头身比与肩腰腕踝位置。单件素材使用实际 alpha 透明背景，去除身体、皮肤和其他衣物，不画文字、背景、落地影子或人台。各素材分别生成，再通过坐标整理脚本对齐。

生成工具不保证像素级保留参考位置，因此不能直接相信其输出画布坐标。最终素材通过 alpha 包围盒、分段竖向校准、头/左右臂和左右鞋分别定位到统一画布，再目测领口、肩、手腕、裤脚。此步骤是换装能够混搭的必要条件。

头颈修正版：原 skin 保留为制作源，按下颌轮廓拆成 `head-base.png` 与 `skin-arms.png`，新颈部源图注册到 `[383,218,191,245]`。颈部上端沿用原肤色和下颌连接，下方补齐开领锁骨，收紧颈侧轮廓以免皮肤露出衣领外缘。白衬衫、礼服内搭在 manifest 应用水平镜像统一朝向；7 张 `*-rear-mask.png` 根据原图 alpha 轮廓分离后领，保持原衣领笔触并校准前后遮挡。接触图覆盖四种内搭与五种外套选择，共 20 组。

## 二轮领口与前后分层（2026-11-02）

继续使用内置图像生成工具，保留的礼服领口与风衣后衬使用真实 alpha PNG。生成文件经机械裁边和坐标注册后进入以下制作路径；不需要外部 API 或新服务。

| 运行时文件 | 用途及最终生成要求 |
| --- | --- |
| `assets/top-formal-v2.png` | 编辑目标为原礼服朝右的版本，头颈局部合成图作为适配参考。只重做白衬衫上领：向后颈侧拓宽、形成连续低圆后领与闭合前领，去掉独立上翘尖片，保留紫色领结接点。输出完整透明内搭，不生成皮肤或人台。最终只注册生成图的领口局部，其余袖子、马甲与腰部沿用原图。此图本身已朝右，`mirrorX: false` |
| `assets/outer-trench-lining.png` | 以驼色前片作为颜色、长度和笔触参考，单独生成风衣内部的连续后背面料：烟草棕/焦糖棕、纵向接缝、长褶皱、浅后领凹口、弧形下摆。面料中央连续不镂空，无前襟、翻领、袖子、口袋、身体、人台或落地影子；外侧透明。注册 box `[302,292,366,892]`，绘制在身体和裤腿之后 |

高领使用原针织素材，不重新生成布料。前后领遮罩改为沿原黑色前缘线绘制，停止向布料内部扩张，从而保留自然的弧形上沿与墨线。新的后层和后领技术层分别命名，避免将外套后背内衬与后领混成一层。

## 原图拆分与对齐修正（2026-11-03）

本轮不生成新发型。原 `hair-black.png`、`hair-blonde.png` 各按头部遮挡轮廓拆成 `*-front.png` 与 `*-back.png`，前后片保持共同坐标和同源 RGB。脸前发丝位于头部之前，后脑、耳后及后颈发丝位于头部、颈部和衣服之后。之前额外生成的长发已从工具移除。

原 `outer-trench.png` 的两片深色内侧下摆从前层中剥离，保留为 `outer-trench-inner.png`，再与后背制作源 `outer-trench-lining.png` 合成运行时 `outer-trench-back.png`；运行时外套前片为 `outer-trench-front.png`。两片内摆和后背均放在裤腿后面，米色外侧前摆保持在前。

头部和两套前后发统一下移 10 px。颈部上端跟随下颌移动，y=285 到 y=350 之间作连续过渡，y≥350 的锁骨与肩线保持原像素。每次从保留的 `neck-neutral.png` 重建，避免累计变形。对应的原发型、内摆 alpha 重组与颈部锚点由可选像素验收脚本检查。
